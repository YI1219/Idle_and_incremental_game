# Rock kit (island underside)

Modeled CC0 rocks used for rule-based floating-island undersides.
Source textures are imported only for completeness; the game ignores them and
colours pieces with a shared world-height rock shader.

## Asset sources

| Pack | Pieces | License | Source |

Neither pack includes hanging roots. Roots are a small procedural tapered mesh.

Placement rules and the approved Blender prototype: `notes/rockkit-test/README.md`.
