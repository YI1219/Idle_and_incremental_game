# Rock-kit asset sources

These files are committed on purpose. The game ignores the source textures and colours
the meshes with `shaders/world/island_rock.gdshader`.

| Path | Pack | License | Source |
| --- | --- | --- | --- |
| `kaykit/` | KayKit Forest Nature Pack 1.0 FREE, Kay Lousberg | CC0 1.0 (`kaykit/License.txt`) | https://kaylousberg.itch.io/kaykit-forest |
| `quaternius/` | Quaternius Stylized Nature MegaKit Standard | CC0 1.0 (`quaternius/License_Standard.txt`) | https://quaternius.com/packs/stylizednaturemegakit.html |

Hanging roots are a small procedural mesh in `scripts/world/rock_kit.gd`, not a third-party asset.

See `README.md` in this folder and `notes/rockkit-test/README.md` for placement rules.
