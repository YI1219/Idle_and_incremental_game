The retained `7f7722c` cliff pass replaces the broad half-unit horizontal lattice with staggered actual rock planes. Identical contour spans and endpoint normals collect elevation bands, then merge contiguous bands so unrelated new elevations do not split distant geometry. Broad columns use maximum 1.15 horizontal spacing, retaining .65 near terrace joins; world-anchored interior Y samples use 1.35 spacing with ±.24 variation. Actual terrace heights and adjacent interval ends remain mandatory. Unequal vertical chains join with zipper triangles. Shared endpoint constraints promote broad/narrow borders to the old fine samples. Strict interval clipping preserves the same interior sample set across merged and split neighbors. Broad triangles retain flat geometric normals; constrained narrow spans retain half-unit rows and smooth normals. The material now lights actual planes, removing its fake normal perturbation, vertical-normal flattening and painted dark joints. Physical relief, taper, wet-clearance math, caps and original assets remain.
