# 《我有一片田》制作结构研究

固定公开提交、文件 URL、SHA256 和忽略缓存路径见 [manifest.json](manifest.json)。此次实际读取源码，不宣称已找回此前本地克隆或旧研究，也不把当前公开提交当作此前看过的版本。

`bank_geometry.gd` 把连续轮廓与受控九层岸坡剖面分开；`island_space.gd` 的 0.5m 格用于空间候选查询，精确多边形判定支撑与碰撞，不以地形砖块量化模型。主场景 Plan、可丢弃程序岛实验、浅岸及远景整岛模型不能混为同一种运行时方案。浅水岸不等于我们的浮岛崖壁；迁移适用性尚需实际母版验证。

文本只作本地研究，未执行上游代码、导入模型或直接接入生产。资产与代码的复用许可须另核实；两项已安装技能各自附带许可证及独立来源记录 `.agents/skills/SOURCES.json`。
