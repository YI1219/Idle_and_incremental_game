`layers_*` 是 7de6abf 阶段实际场景分层截图：移除根石、mantle、backing、侧石阴影以及类别色。去根石/阴影仍有台阶，证明不只是光照，突出底脚与下部体块的连接有问题。类别色仅用于诊断，不是候选美术。

Codex 直接操作 Blender 5.2.1 LTS，编辑保留的 main_v4/tall_v2 副本；原件哈希不变。工作文件和灰模在 `art/work/cliff_connection/2026-10-15/output`，精确参数/哈希/闭合体积在本目录版本 JSON。

- v1：下截面按高度平滑向内平移，原面数 634/816。虽然高处顶点不动，跨越低截面的长边仍改变 .62 cap；实际运行对照像悬挂薄片，否决。
- v2：在归一化高度 .55 增加保护截面，主模型 826tri、高模型 974tri；Blender 中 0 非流形/退化面，体积为正。但运行加载丢弃细小三角，4 种剪裁出现闭合失败；边界误差也并非严格为零。`connection2_*` 是未通过验证的否决试版，不能当作功能通过或最终形状证据。
- shell1：仅在诊断截图中试推外层支撑壳，未接入权威地形；位移缺少局部深度约束，拉伸远处/内部面，产生尖角和水体异常。其着色对比无效，已否决。脚本留在本地 work 目录作实验记录，不作为可用运行工具。

收脚 GLB 没有保留到 assets；运行源与 7de6abf 字节一致。以上不是当前待办，也不要求用户提供模型。不要再把独立收脚或扩大壳体当成已经成功的自然连接。
