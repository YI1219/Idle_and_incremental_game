# 水流、泡沫与轻雾 — flowing4

## 改善与限制

减轻瀑布前厚重的雾层（默认opacity.26→.10）；落水泡沫由始终不透明的白垫改为随时间变化的部分覆盖，外圈亮线出现移动缺口。保留蓝绿色主体厚度与零散向下移动的白色水包，降低细法线和镜面闪烁。首次水流试版太薄、第二版透射太强，均拒绝；第三版的主体配色保留，修正位移的双轴投影/clip.w换算后选为flowing4。

水体背后的不透明画面可被轻微折射，位移默认.045m，经相机投影换算；扭曲采样若落在瀑布前方物体上则回退原UV。透射部分不再按表面漫反射重复照亮。只是当前屏幕近似，不能折射屏幕外或其他透明层；这不等于完整物理水体。未实测多种缩放、正交、移动镜头和透明层关系；不据实现公式声称这些外观已验收。新增每瀑布像素的屏幕/深度采样，目标设备GPU成本未知。

运行改动只在三个shader，保留原瀑布/泡沫/雾几何、落点/宽度/深度元数据、岛形、实际湖底、树木建筑、编辑与支撑。未增加装饰、模型或纹理。`foam_time`默认-1跟随TIME，非负值仅供固定相位验证；生产默认不冻结。

## 实景证据与取舍

十张分层实际近景分离主体、雾、镜面、光照和泡沫。关闭雾能明显移除白色覆盖，关闭镜面主要移除闪点；移除泡沫消掉了白垫和圆圈。因此本轮不是单纯把水流调暗或删掉。

11张最终全场景截图逐张核对与mineral2相机位置/旋转相同，检查庭院、全岛、远景、草土、池岸、岛缘、反向、底面8个主视角。另在实际两条瀑布各取.5/1.2/2.4三个固定时刻，提供六组严格同镜头、同相位近景前后。基线使用2854203的三个shader文本载入同一实际场景，水面和湖底动画也固定在对应时刻。对照页两张瀑布近景是.5时刻原图的无修改副本。

独立复核检查六张当前近景和四组主视角，支持作为局部改善保留：白垫减弱、水圈断开、闪烁更安静，远景仍能读到瀑布。没有Critical/Important正确性缺陷。**仍有明显薄幕感，岩面仍能透见，水圈几何仍太规整；不视为自然水体或整体美术接受。** 崖壁宽平板、草皮硬切、岸边直带/水光网仍需继续改善。
