# Source connection and worn-source studies — all rejected

The user-endorsed `art/source/visual_targets/2026-10-16/cliff_user_target.png` remains the visual target. None of these trials reaches it or replaces the current `spall_finish1` default. This round changes tools/evidence only: production scripts, shaders, scene, textures, original stone assets, trees, buildings and authored terrain remain byte-for-byte at `bb44093` within the checked runtime paths.

## Actual trials

`source_return1` samples actual imported crown front sections over five representative front-left columns. It extrapolates their lower slopes into the existing core vertices rather than following an unrelated contour. The core and mantle share a position cache; 2,580 vertex occurrences move by at most2.490305m, with no zero-area faces detected. This is a capture-time geometry study, **not integrated editable regeneration**. It produces a broad vertical backing, abrupt basal steps and exposed small triangles while retaining the two-layer read. Rejected. Zero degenerate triangles is not proof of closure, collision correctness or absence of self-intersections. Nearest-row filling, clamped slope continuation and a feathered displacement blend are study approximations, not an accepted natural connection method.

The three `worn` versions refine **existing integrated main/tall source copies** in Blender5.2.1LTS. Original files are unchanged. Each copy has a saved `.blend`, grey `.glb` and source/provenance JSON in `art/work/cliff_worn/2026-10-16`. They are not new original official assets, generation tasks or runtime dependencies.

- `worn1`: convex edges over25degrees receive a physical two-segment bevel of5.5% of the smaller horizontal source dimension, profile.60. This barely changes the actual scene and does not justify its added geometry. The source files are manifold, but the clipped runtime `cliff_column_d` diagnostic reports six non-two-use edges. Rejected.
- `worn2`: the same copies receive voxel remeshing at2.5% width, four.55 smoothing iterations, one shallow Clouds displacement at17% spatial scale/3.5% strength, then24% simplification. `worn2` retains the old42degree/.28 source-normal blend; `worn2smooth` uses the same source geometry with full shallow-angle normal smoothing. Near faces lose some coarse triangle transitions, but the broad bodies become soft/molded, the thin grass cap remains and the separate lower body dominates. Four uploaded clipped crowns have zero non-two-use edges in this finite check, but their counts become3,478/3,606/3,678/3,382triangles versus the original722/698/768/602—about five times as many. Neither warrants promotion.
- `worn3smooth`: same wear process,6% simplification instead of24%, full shallow-angle normal smoothing. Counts fall to928/948/972/910. Whole-view improvement remains insufficient, small exposed triangles are visible and `cliff_column_c` reports six non-two-use edges on actual uploaded arrays. Rejected.

The tool substitutes only the four crown kinds for wear studies. Existing full outcrops, low shelves and other sources remain original. Caps intentionally follow each refined source; their raw bounds are allowed to change, unlike the earlier corner-cut study. This changes final derived cap contours, plants and vine attachment. Do not claim pixel-identical layouts or support simply from unchanged authoritative cells. The geometry-source hash fields in the two smooth capture reports hash hexadecimal text of packed vertices; that algorithm is explicitly recorded in `validation.json`.

## Consequence

Do not promote these sources, extend the profile displacement further or keep sweeping bevel/noise/normal settings. Surface erosion cannot fix the slab/core proportion, and row-wise continuation does not create a coherent three-dimensional union. Any next geometric candidate must prove a small actual volume with a shared upper-ground boundary, unequal adjacent face thickness, and a continuous lower return from front and reverse before propagation. This remains a geometry problem we can investigate; no missing user model, Tripo operation or other external delivery blocker has been established.
