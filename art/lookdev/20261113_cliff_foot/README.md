# 外层岩壁底缘收束 · 2026-11-13

**本压短方案已被用户明确否定：像小凸包、破坏岩层错落。当前版本请看 `../20261113_cliff_join/compare.html`。以下只保留被否定候选的技术记录。**

用户指出外层延展岩壁垂过主体底部、形似护甲。本轮唯一生产改动为 `scripts/terrain_editor/terrain_decoration.gd`：保留外肩顶点锚定平面，按实际斜切网格缩短局部 Y；底点高于跨度中心／两端最浅地形脚与父岩实际底点，留 0.35m 余量。网格本体、岩型、主 columns、顶冠、内台阶足石、地形数组、shader 与光照参数保持。

缩短会微移实例原点；现保存原 `tone_origin`，发布 MultiMesh 时使用该点取原有矿物色，避免触发 5cm 量化随机色的重新抽样。没有引入运行开关或另一套场景。

- `compare.html`：默认种子 7301 的 9 个同机位前后对照，另有 2104／4242／913 与默认夜景。
- `before/` 为任务起点 9 张；`final/`、`final_held2104/`、`final_held4242/`、`final_held913/`、`final_night/` 为最终 45 张。共 54 张实际 Godot 原生 2560×1440，Forward+、4×MSAA、固定相位 1.25。水先演进 .1s 再冻结；默认日照 .29，夜景 .00。
