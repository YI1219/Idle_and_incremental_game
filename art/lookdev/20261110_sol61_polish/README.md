## 尚存的边界

局部草缘仍较整齐，岩壁拼接与少量薄竖缝仍可见。踏石形状仍略像等距薄饼。瀑布水丝略偏白、偏齐，外瀑左缘中下段仍有短亮条/小台阶。原岩面细自阴影纹保留，不能为去纹牺牲用户认可的转折清晰度。

底部内缩、新增heel环、任意偏移脚点的三个试验未采用；最后一种虽封口正常，却令下段四边形扭折。新增共面回归先复现8/24失败，再用原平面公式修正到24/24通过。相关补丁与RED/GREEN记录在checks，失败实拍仅留工程追溯，不进入Downloads审阅镜像。

瀑后矩形的投影位置与不透明湿岩结束位置吻合，尾部alpha在该处连续，新的mist卡片在其下方，诊断见 `checks/waterfall_followup_probe.json`。真实透明透底和screen注入各自的定量份额未完全分离。最终以同机位实拍验证残留减轻；未宣称全角度透明合成已完全解决。
