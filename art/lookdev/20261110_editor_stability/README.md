## 变化与用法

- **4K预览**：默认“流畅预览”，3D渲染最多2560×1440，4K窗口与界面保留4K；使用空间放大并降低高分辨率预览的多重采样。底部“卷”菜单可切“原生画质”，恢复完整请求分辨率与原有采样。2K及以下不降内部渲染分辨率。草叶远景使用更少的弯曲分段，近景完整顶点、颜色与法线保持；未以雾/曝光/关掉SSIL来代替优化。
- **淹水地面**：按实时绝对水面与草根高度判断淹没，草地改用既有湿泥石底色，真实草叶与草唇完整收束；退水恢复原草地。上方未淹的高台草仍保留。树、灌木、石头维持独立自然物，不因这一草材质修正被删除。有限水量求解器未改变。
- **裂痕/薄片**：新坑与内凹岸边的部分源岩柱只有侧背墙，缺少匹配冠顶，沉降会把它们暴露成悬片。现在裁退不安全内台阶柱，缺少包覆的干台阶用同一岩壁表面连续连接高、低地面；真正贯穿空洞保留。三种子原始30根柱中5根内部不安全柱回退，所有外圈柱种类与位姿逐项相同。初始内部台阶局部外观也因此改变。
- **地面齐平**：底部新增“齐平”，在希望保留的地面按下，拖过待调整区域，松手提交；高、低地面都统一到落笔处高度。默认开启贴格，笔刷范围内显示局部格线；卷菜单可关闭。仍支持蓝图、右键取消、一次撤销，水量不随齐平/撤销凭空补回。

## 证据来源

- 水下草比较：`flooded_final/` 在同一实机场景内，仅切换本任务前后三份草材质源码及对应include，几何、水量、相机、灯光、相位相同。两次降低后真实演进3秒，11个原干地格被淹；留存+外排守恒误差约1.61e-12。排水恢复图用既有dry工具，不声称封闭池会自然排空。
- 裂片比较：`scene_review_final/` 在内存重建本任务前两份几何生成器，再切当前几何；共用当前草材质、LOD、水场，不是整个旧工程复刻。上层四笔降低正反向、下层四笔降低、held2104/4242均保留。比较帧数据哈希/水量/机位/光照完全相等，过渡已结束。
- UI：`controls_review/` 用生产鼠标输入点击齐平、拖动、右键取消、松手、撤销和画质/贴格菜单。齐平9格到3.5m，取消/撤销恢复；4K菜单在scale1与2/3之间切换正常。
- 所有最终采集时源码稳定、人物缺席。BASE全景正反向另检，既有认可岩面材质、光照与远景没有改动。局部曲面仍可见折线、岸缘草片与瀑布硬边，功能修复不等于完全达到TARGET美术质量。
