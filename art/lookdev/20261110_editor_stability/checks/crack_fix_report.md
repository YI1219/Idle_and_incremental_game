# 内部降低裂缝修复

2026-11-10。任务范围为 `crack_fix_task.md`。当前生产改动仅 `terrain_decoration.gd` 与 `contour_terrain.gd`，新增实际几何回归 `tests/interior_terrain_edit_test.gd`。本分任务起点保存在 `source_before/interior_crack_fix/`，精确补丁及哈希为 `interior_crack_fix.patch`、`interior_crack_source_audit.json`。

## 根因和生成修复

- 原始两条真实源柱网格射线先得到 RED 2/2，命中位置分别为 `(-9.148115,2.862362,-7.141125)`、`(-10.654700,3.095045,-6.722658)`，其下权威草面为1.5。闭合负环和开口notch均能暴露 wall-only 冠柱侧背面。证据为 `interior_crack_red.log` 和已有 `edit_cracks_diagnosis.md`。
- 对 dry interior step 的真实 render faces 检查顶点、边中点和三角形重心。侧面进入较低实地而缺乏累计上层轮廓或有效冠顶覆盖时，整根源柱回退。依次重检，避免继续依赖已移除柱的冠顶。对应内台阶脚石按 `crown_edge` 一起移除。实际贯穿空洞没有低层实地接收面，保留原生成逻辑。
- 仅移除不安全源柱还不足以保证支撑。`interior_support_red.log` 与 `interior_support_probe.log` 定位到相邻湿端点的 `bed_top` 将干台阶一端夹低，以及后续 normal recession 折离中段。现在 `close_unclad_dry_steps()` 按所有无有效源冠覆盖的干内台阶权威轮廓生成完整连续立壁，上下分别接真实高、低cap，合并进同一 `surfaces.cliff`。保持原材质，顶冠与下层地面没有随修复扩张。
- 负环和正环notch采用相同的覆盖/接收面约束。未使用编辑历史特判，未修改 `rim_union`、湿瀑口、材质、光照、拾取或其他任务文件。
