# 2026-11-12 天空方向数学与后处理优化

[实际 Godot 对照](compare.html) · [完整验证](checks/final_validation.json)

本轮在上轮14面远景草、2×MSAA、4096阴影基础上继续优化。仅四份天空相关shader、preview_quality和采图工具改动，无模型、默认资产、地形、水量或玩法扩展。

## 保留改动

- 天空、云海、远山直接由视线求高度、太阳角距和暖侧权重，减少方向→角度→方向往返。颜色、HDR、混合和雾常数保持；旧角度接口仍可用。
- 精确极点回退旧路径，保留atan(0,-0)的后端行为；近极点保留原1.57弧度夹角。调用者提供非零视线，已注明前提。GPU日夜球面、南北极、近极点和signed-zero测试4项通过，采样输出8bit像素差0；不是所有浮点输入的形式证明。
- 默认SSAO只改半尺寸，质量、强度、范围、模糊次数不改；景深保持强度/焦距/过渡/jitter，仅Low→VeryLow采样。SSIL与云细节保留，景深没有关闭。
- “原生画质”按ProjectSettings恢复原AO和景深采样，既有MSAA/阴影恢复、动态分辨率和壁纸限帧保留。采图元数据新增AO半尺寸与景深质量。

## 实测

M4 Pro、Godot4.7.2、Metal Forward+。固定尺寸SubViewport的正常渲染循环，生产editor真实水/光照持续更新；同机位、像素数、2×MSAA和4096阴影，每组3秒预热+8秒采样，关闭VSync/限帧，无截图I/O计入，图形进程串行。

| 相同渲染条件 | 本轮前FPS | 本轮后FPS | 增幅 |
|---|---:|---:|---:|
| 2560×1440原生像素 | 51.87 | 57.51 | 10.9% |
| 3840×2160原生像素 | 25.49 | 28.62 | 12.3% |
| 3840×2160输出、固定1920×1080内部3D | 64.05 | 68.66 | 7.2% |

p95分别21.71→19.86、41.79→37.36、18.10→16.90ms。“原生像素”指scale1，仍使用上轮2×MSAA/4096阴影，并非开启最高采样的“原生画质”开关。运行水演进约11.1秒，前后一致。

固定状态AB/BA复采支持收益：2K约19.5→17.5ms，4K40.0→35.8ms。仅方向数学约省4K不到1ms，其余主要来自后处理采样。关闭景深/AO、低SSIL仅用于诊断，未采纳。最终固定测试使用variants_final.log及variants.json；早期variants.log的旧shader TIME冻结正则曾多写转义，已修正并重测，不采用早期数据。

8秒单轮运行不代表任意镜头/长时负载；4K全像素仍慢。壁纸正常保持30FPS，不能把不限帧吞吐提升说成壁纸实际帧率变化。目标Windows轻薄本/MacBook Air、温度和整机功耗未测。
