下段用保持平面的投影变换接合，切口落在实际父岩内部；独立面属性保留，微小裁切点焊接后去退化面，底盖直接复用实际侧面边界。网格存在原 contour run 缓存，未变轮廓复用原资源；chunk 签名包含新网格几何摘要。
