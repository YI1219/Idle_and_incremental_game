# 松手后的即时渐变反馈

用户希望用便宜的渐变特效承接地形生成期间的等待。已在唯一入口 `scenes/terrain_editor.tscn` 接入，审阅入口为 [compare.html](compare.html)。重新运行场景加载。

沿用现有蓝图网格与青玉色。松手当帧增强局部渐变流动，新增区域轻微浮升，移除区域浮散。开场运动约 0.35 秒，随后持续流动等待真实地形。真实地形显现到 65% 时，特效用约 0.18 秒淡出交接，与剩余地形动画重叠。

取消下一笔会恢复上一笔已提交的反馈，撤销会按当前权威地形重算显示差异。反馈网格在等待期间复用，采用既有透明平面加简单正弦色光。

本轮实现顺序为真实入口反馈回归、三个生产文件修改、原生时延测试、同机位动画检查。初轮交接偏早，原生自检后推到地形大部分显现时，新增对应回归。

## 原生 2K 实测

Apple M4 Pro，Godot 4.7.2，2560×1440。使用生产 begin/continue 与全局鼠标松手入口，原有异步构建和动画时钟，固定相机，显式整帧绘制。采样期无截图写盘。编辑器父循环由测量工具按生产顺序调用，水在地形待发布时暂停。

| 操作 | 松手回调 | 首帧反馈完成绘制 | 真实地形发布 | 地形过渡完成 |
| --- | --- | --- | --- | --- |
| 中笔短点抬升 | 0.10ms | 14.28ms | 709.97ms | 1255.83ms |
| 长按已预建抬升 | 6.99ms | 28.59ms | 6.86ms | 578.37ms |
| 中笔短点收缩 | 0.10ms | 14.14ms | 753.03ms | 1299.05ms |
| 阔笔短点抬升 | 0.25ms | 14.56ms | 726.30ms | 1271.48ms |

反馈网格最近一次构建约 0.74–0.83ms，绘制期间已有同一网格时，松手复用。首帧和发布测量边界不同，已预建案例可在首帧前发布。

此改动改善等待期间的响应和交接。真实网格重建仍需约 0.7 秒，完整过渡约 1.3 秒。上一轮原生 4K 运行偏慢的问题仍待继续优化，这组时延测量为原生 2K。
