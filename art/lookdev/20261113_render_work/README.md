# 非水体渲染优化 · 2026-11-13

用户要求扩大优化范围，岩壁现有色泽和光影是保护基准。生产只改 `scripts/gameplay/systems/time_solar_system.gd` 的天空辐射贴图调度；新增 `tests/sky_update_test.gd`。没有改岩壁/植被/云海几何或shader、配色与照明常量、后处理采样、分辨率、内容或玩法。

## 已落实

天空原本固定使用QUALITY，但昼夜系统约每0.08秒更新其uniform。普通昼夜更新改用INCREMENTAL：使用相同的高质量重要性采样与相同辐射贴图尺寸，跨帧处理。初始化、手动预设、set_progress、step_shichen和反序列化仍请求QUALITY，并记录渲染帧；同帧普通tick不能取消完整更新。至少经历一个绘制帧后，例行更新才允许分帧。

官方说明：https://docs.godotengine.org/en/stable/classes/class_sky.html#enum-sky-processmode

这是调度优化，动态环境光存在很小的更新滞后。当前唯一正常视口下验证；全局frames_drawn不能证明独立隐藏SubViewport已绘制。未来若支持不同步的多视口，需要逐视口完成跟踪。

## 真实实时渲染实测

M4Pro/Godot4.7.2；正常编辑器/水/昼夜实时运行；固定SubViewport实际像素与当前balanced设置；3秒预热＋8秒采样，ABBA各两次；无VSync/限帧/截图IO。before用兼容子类仅强制旧QUALITY调度，其他代码相同；after为生产策略。

|输出/内部3D|FPS前→后|P95帧耗时前→后|P99前→后|
|---|---:|---:|---:|
|原生2K|56.71→57.55|20.34→18.27ms|21.03→18.78ms|
|原生4K|28.24→28.63|37.99→36.10ms|38.74→36.60ms|
|4K输出/1080p3D|67.64→68.36|17.35→15.78ms|17.99→16.64ms|

平均FPS提高约1–1.5%，主要收益是较慢帧减少约1.6–2.1ms。没有解决原生4K60FPS；目标Air/Windows轻薄本、温度和整机功耗未测。原始数据与实际scale/texture_size、sky_mode见checks/runtime_final.json及runtime_summary.json。

## 画面与验证

- `compare.html`：30张实际原生2K/15对，四布局正反近景、主布局低角/夜景/黄昏。固定机位/种子/水/相位与色光参数，QUALITY对INCREMENTAL稳定输出，15对逐像素相同；已检查多角度整体，未推断用户已美术验收。
- `dynamic/comparison.json`：双独立世界640×360，固定shader相位，逐帧手动推进相同1/60秒。168帧覆盖慢速昼夜和三次手动跳转。连续颜色统计用160×90降采样，最大差1/255；保存18个640×360关键帧，完整像素复核最大差也为1/255、最大均差0.0318/255。初始双世界静态控制像素一致。手动跳转均保留QUALITY，未观察到旧光照长时间残留。
- 新调度回归8项，RED2失败→GREEN0失败，覆盖手动/同帧/普通推进与再次切换。33组当前阶段回归通过(28headless+5native)。旧gameplay_m1_m2_test依赖已删除二阶段人物，按已知不适用排除，不是通过项。
- 独立只读审查无Critical/Important；明确多视口、目标硬件和功耗边界。普通唯一入口90帧通过，所有本轮进程退出，仅保留用户原编辑器。

## 试过但未落入生产

在内存中测试了岩壁噪声角点复用、云海计算顺序、稳定材质移除过渡discard。正常实时循环没有可靠吞吐收益，未修改对应生产shader。早期force_draw临时探针受shader重编译/辐射贴图重建与双绘制节奏干扰，前后漂移很大，仅保留原始记录，不用作收益证据；正式结果采用独立进程正常循环ABBA。

## 仍可推进的较大策略

1. 岩壁材质：分离静态位置相关色层/遮罩与动态照明，缓存前者；保持当前动态光照、法线与配色。需要先证明材质成本，前述局部噪声改写无收益，不能据此承诺缓存收益。
2. 云海：独立低分辨率渲染或分层合成，保留岛和岩壁前景清晰度。涉及深度、透明排序、折射和远山遮挡，需专门原型；不是直接降低整个3D分辨率。
3. 植被：按屏幕占比选择着色复杂度，裁掉卡片中完全透明的区域，保留叶缘、群落密度和近景。现有MultiMesh及三档草LOD已存在，不能当作新收益。
4. 地形：局部轮廓/网格准备与增量发布，避免编辑小片却准备整岛，主要改善编辑延迟和扩建增长，不直接解决固定画面的GPU成本。
5. 阴影/深度：可验证同位置的紧凑shadow_mesh和顶点复用；不能改变岩壁受光、接触与投影后直接称优化完成。

所有未来项仍是待验证方向。继续只保留可靠提速且通过画面对照的改动。

回退只用checks/source_before/time_solar_system.gd和最小patch，不整体恢复其他dirty工作。
