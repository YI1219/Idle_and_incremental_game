# 岩壁接合修复与当前使用体验

2026-11-11。唯一入口仍为 `scenes/terrain_editor.tscn`。本轮只修改两个生产文件，材质、光照、人物缺席与自然物独立编辑保持现状。

## 当前体验核查

蓝图编辑/取消、异步发布、一次撤销、落笔平面、镜头控制和松手渐变的本轮回归均通过。短点等待和4K表现沿用前轮实测边界：真实地形约0.71–0.75秒发布，完整过渡约1.26–1.30秒；4K流畅预览依赖动态内部1080p–2K。这里没有重新进行时延/帧率基准，不将旧数据冒充本轮测量；Windows轻薄本与MacBook Air约60FPS仍未实测。

## 两处修复

1. `block_mantle.gd`：原先共享接合点按各三角面第一顶点的台面高度内缩，产生不同位移。现在使用同一量化顶点组的最低台面约束，保住低台阶接收端。真实初始/内部降低/局部抬高输入的分裂点从8/8/14变为0/0/0。专项28项，原版11失败、现版0失败，包含两种三角面顺序、混合顶点高度和上下接收面。
2. `contour_terrain.gd`：封口只检测整段中点的顶冠覆盖，导致“中点已覆盖、前半段暴露”的岩壁漏补。现在按实际顶冠边线交点拆分，只补未覆盖区间，并对各区间重新检查接收面干湿/底高。三种子专项24条严格距离射线，旧封口16失败、新版0失败。最初扩大到冠内的2104/t=.3两条断言不属于补壁范围，已明确收窄fixture；早期日志保留。

## 实机证据

- `compare.html`：9组同场景前后对照、18张原生2560×1440截图。重点先看“斜角凹窗”。种子7301/2104/4242，正反面、斜角、夜景与局部抬高。
- `final_junctions/`：最终局部实拍；前后在同一个live scene内只切换本轮两处生成逻辑，使用当前其余生成器/材质。水流显式推进0.1秒后冻结；相位1.25、4×MSAA、原生2K。每对所有相机/光照元数据逐项相同，源码哈希与当前生产文件相同。
- `before/`与`final_whole/`：任务起点与最终默认场景5机位实拍；`final_whole`为最终生产状态。
- `junctions/`、`after/`、`edit_before/after/`仅为第一处修复或诊断阶段，不作为最终交付画面；Downloads镜像不含这些中间截图。
- `checks/task.patch`为相对任务开始时两个源码的精确补丁；不要用整体git回滚覆盖先前dirty工作。

## 检查与边界

27组当前适用检查通过（24组headless、3组原生），另1份旧二阶段测试失败。完整结果见 `checks/final_suite.json`、`checks/native_suite.json`。内台阶支撑检查含460向下/672水平射线，瀑口封口16项。三个原生像素/LOD测试通过；草恢复像素测试只改了测试输出目录以避免覆盖旧证据，生产逻辑未改。只读审查没有发现重要新问题。

全量扫描另碰到旧 `gameplay_m1_m2_test.gd`：仍断言默认avatar并访问已删除人物，产生空引用后超时。日志为 `obsolete_gameplay_diagnostic.log`，不属于通过项；本轮没有恢复人物或修改二阶段系统。

本轮没有消除所有薄尖轮廓/源岩块搭接。共享点修复不负责焊接原本坐标不同的点或T形接边；冠内投影也不保证整片侧壁遮挡。原整段中点的干湿早筛仍可能漏过“中点湿、局部干”的混合段，此轮没有扩展该范围。局部新补壁偏直，观感仍需用户验收。功能测试不等于美术验收。
