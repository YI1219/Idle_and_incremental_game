# 蓝图编辑、地形过渡与有限水流

2026-11-10。唯一生产入口仍是 `scenes/terrain_editor.tscn`。打开 `compare.html` 查看对比、交互阶段、水量演进与壁纸。Downloads 镜像：`~/Downloads/scroll_interaction_water_20261110/`。

## 已实现

- 细／中／阔按钮扩大点击范围、显示文字与单一高亮；默认中笔2.2。右拖固定观察距离旋转，滚轮按距离联动19–68度俯仰。
- 光标命中地面或侧面所属台阶的顶面，整笔锁层；同层相连扩张，收缩不穿到低台。填回孔洞保持原指针位置，不因碰到侧墙而偏移。
- 左键按住绘制独立蓝图，真实地形与拾取保持不变；松手一次提交，整笔一次撤销。右键、Escape、失焦取消。无法操作的区域显示红色，额度检查包含当前蓝图。
- 新增升起淡入，移除下降淡出，过渡约0.55秒。等待后台网格时保留蓝图；过期草稿提前停止计算，已撤销的后台结果不会重新出现。
- 原有远端岩块分段与位姿保持稳定，新边缘沿用原岩型。紧邻改动处需要重新接合。保留远端chunk与完整重建的草面三角划分不保证逐顶点相等。
- 连通水面摊平，有限水量依出口床面与落差流向下池；流出岛外累计记账，没有隐形水源。水几何独立更新，不因水位变化重新生成旧岩壁。地形高度撤销/重做保留当下水量，不从历史补水；保存和加载保留连续水量。
- 瀑布改为单层玉色流水、不同长度的运动反光、落点小水滴与局部飞溅。修复退水后仍悬在原水位的旧岸坡横唇，使固定出口对齐真实床高。取消左右端随落差靠拢的几何处理，保留真实口宽；实际邻近流量不能误挂到本池侧墙。弱流逐渐淡去，物理体积不因显示阈值而删除。

## 松手等待：仍有明显余量

Apple M4 Pro开发机，Godot4.7.2 / Forward+，1280×720，正常水流开启。每类操作一次诊断采样，不是多次重复的延迟分位数。原连续笔刷每次完整后台生成约1.0–1.27秒，当前绘制提前准备，松手结果如下：

“发布”是地形切换并启动升降的时刻，实际画面还需下一帧。短点和最后一刻仍在移动的长拖尚未即时，不把预览高亮当成真实完成。过期任务提前终止后，拖动抬升在本次诊断中由约1.69秒降到约0.69秒；两轮单次采样不构成稳定性能分布。绘制中指令处理通常低于1ms，帧间隔p95约21–24ms；这不等于目标硬件60FPS已达标。

原始数据：`checks/continuous_brush_before.json`、`blueprint_native_benchmark.json`、`blueprint_native_benchmark_cancel.json`、最终`blueprint_current_benchmark.json`。速度采样不包含图片读写。Windows轻薄本与MacBook Air未实测。

## 水量与边界

默认场景初始71单位体积，60秒后留存约38.769166807，累计外排约32.230833193，总量误差小于1e-10，地形床面保持不变。见 `water_evolution_review/water_evolution.json` 与0/10/60秒同机位图。

采用网格上的有限体积、连通池面与出口流量，未加入三维动量流体。显式绘水/排水工具属于用户编辑；自然演进本身不会增加水。抬升湿桥造成分池时，桥上原水量分配给直接相邻的湿分区。每次后台推进不超过0.1秒、排队不超过0.3秒；长时间停顿不无限追算。编辑网格待发布时水流暂缓，避免可见床面与水体错位。

## 审阅内容

- `final_day`、`final_night`：最终原生2K、4×MSAA、固定相位1.25、生产F11清屏。whole/reverse/cliff_close分别锁BASE A/D/B；game/close为瀑口正面与原空腔斜角。日景.29，夜景.00，种子7301/预设0。人物、旧屋缺席。
- `waterfall_before_day`：同一当前场景中，仅用任务开始时保留的源码恢复旧瀑布几何/材质/雾。当前地形与live pool保持相同；不是整个工程的完整旧版本。旧mist源码从上一包source_after恢复，并核对上次封口实拍的SHA256。前后机位、光照与data哈希相等。
- `controls_review`：真实控件文字区域点击、笔刷半径1/3.8、近远俯仰与固定距离右旋。
- `interaction_ready`：生产Viewport输入的蓝图、取消、红框和增删阶段帧。固定过渡进度采样，非实时性能录像；为看清形状隐藏面板，保留画笔。
- `water_evolution_review`：生产求解器按0.1秒推进，离线加速采样，不是实时录像。每阶段拍全景与瀑口，权威床面不变。
- `held2104`、`held4242`、`held913`：保留种子全景与斜角，后者干岛。
- `wallpapers`：A/B/C/D为最终原图字节复制。`references`仅为sol61生成参考，参考中人物不代表人物恢复。
- `checks`：回归日志、审查、源码前后快照、任务补丁、采集工具与核对结果。工程保留早期失败/候选帧用于追溯；02–09、早期interaction/evolution与probe不进入Downloads审阅镜像。
