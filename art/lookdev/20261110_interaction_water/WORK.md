## 设计与实现顺序

- [x] 蓝图。左键拖动只改独立草稿数据，显示增删预览，松手原子提交为一次撤销记录。右键/Escape/失焦取消。不可操作位置红色指示。等待构建时保留蓝图反馈。
- [x] 编辑过渡与性能。发布时保留退场网格，仅删除区域下降并以稳定覆盖淡出，新增区域升起并淡入。重用未改网格与拾取数据。性能对比沿用现有实机笔刷基准，并新增蓝图拖动／松手路径采样。
- [x] 局部岩壁稳定。已有轮廓的分段不可因远端增加/删除而全局重排。新边缘采用相同岩型，紧邻变更的接合允许重建。
- [x] 水量。水深是连续体积，单位网格面积1m²。连通池面摊平，过低口按落差外流并进入接收池；流出岛外计入累计排出量。没有隐形补水。物理床面来自现有 cells.height，水面与瀑布动态渲染不驱动旧岩壁重建。
- [x] 瀑布。水口依据床面/水面落差产生，截面保持口宽，采用薄透玉水与运动反光，白色集中在断流及落水碰撞处。接收池有水花和扰动，退水后减弱或停止。
- [x] 验证。真实输入的蓝图提交/取消/红框、连续编辑、增删半程/终态、远端旧岩块稳定、封口回归、守恒与摊平、同机位瀑布日夜实拍，工程与Downloads审阅包。

## 方法选择

编辑采用松手提交与后台重建，降低拖动期间的昂贵生成次数。水采用地形网格上的连续体积与连通池面，水几何单独更新，避免逐帧重建整岛。该方案优先保证水量守恒、可读池面及已有岩壁稳定。
