# 远景分层与植被候选 · 2026-11-13

本轮保留云海/远山的渲染分层，未改变岩壁网格、材质、色光常量、近景植被数量或水量算法。唯一入口仍为 `scenes/terrain_editor.tscn`。

- 远山、-28m以下四层远云及背景天空改在半宽半高的线性 HDR 子视口绘制，通过天空背景通道合成；主天空 cubemap 保留相同数学，最终曝光/后处理只做一次。
- 岛腰两层云、岩壁、草木、水和前景仍使用原有主视口。超过270万内部像素才启用，低于230万停用，避免1080p额外开销；“原生画质”恢复原背景。
- 镜头与色光逐帧同步；首帧/尺寸变化先暖帧。最小化明确停止子视口，恢复后重新暖帧；退出恢复材质与渲染层。扩建/镜头越出安全范围或前景低于远云时回退原深度渲染。

原始数据 `checks/runtime_final.json`、汇总 `performance_summary.json`，工具 `runtime_final.gd` / `finish_validation.py`。`final_2k_a1.json` 等早期不可见探针存在大量跳过绘制，记录的循环FPS虚高，**排除**；旧prototype性能数据仅供筛选，不作为本轮最终结论。不能据此推断MacBook Air/Windows轻薄本60FPS、温度、整机功耗，原生4K仍慢。当前岛仍不是大量可见内容扩容测试；本改动主要降低固定远景像素成本。

## 画面与取舍

[compare.html](compare.html)：32张实际Godot原生2K图/16对，四个布局7301/2104/4242/913，正反/近景、主布局低角/高处/夜/黄昏。每对地形、水、机位、相位、曝光和色光元数据匹配，采图期间源码未变；起点使用本轮前原始天空代码，最终使用共享天空函数和生产分层。已查看整体对照。不是用户美术验收。

全图平均RGB绝对差0.0098–0.0556/255，差异>3级像素占比最高约0.441%；局部最大88/255位于4242反向图的瀑布边缘，放大对照 `pairs/largest_difference.png`。主布局选取三处岩壁内部和地面小区域抽查最大1/255，不能扩展为全部前景逐像素相同。统计见 `pairs/pixel_comparison.json`。

分层把远景深度合并到天空无限远，可能略改变远山景深、轮廓采样和极少数折射边缘；半分辨率背景没有MSAA。近景分辨率、主光/补光/环境光常量保留，不称无损。原型16机位首帧/次帧诊断未见额外整帧镜头延迟；生产同步/生命周期由原生23项覆盖。

## 未采用的候选

- 额外全屏不透明合成面增加主视口成本，未采用。
- 植被透明像素提前discard、完全相同顶点复用（每卡12→5顶点、面数不变）已制成可逆原型，22项headless检查通过；原生采样没有建立可靠收益，未合入生产。不能把atlas透明texel比例或58.3%顶点减少直接当作FPS收益。详见 `checks/foliage_notes.md`。
