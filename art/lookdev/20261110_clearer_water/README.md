# 水体轻度清澈化

[查看前后实拍](compare.html)

本次调整水体主材质的水色吸收、倒影覆盖与折射扭曲。吸收系数从(2.35,1.12,0.98)降到(1.78,0.84,0.76)，近岸吸收倍率从0.62降到0.58，倒影强度从0.58降到0.47，折射偏移从0.012降到0.009。生产修改位于 shaders/terrain_editor/water.gdshader，共三行，前后源码与补丁在checks。

浅岸透射略增，水色稍轻，池底明暗更容易透出，变化幅度较温和。深水及倒影仍有柔化感，倒影边缘的锯齿仍可见。

保留16张原生2560×1440实拍，日夜各四组前后。每组在同一个已生成场景内切换两版水材质，固定相机、灯光与动态相位1.25。before在内存中使用checks/water_before.gdshader.txt，after使用当前主材质。captures.json的source_sha256记录磁盘源码，逐图water_shader_snapshot_sha256记录实际切换的水材质来源。

较早分次采集时遇到岩壁源码同步更新，因此正式审阅只使用04_day_pair、05_night_pair。它们通过场景数据不变、磁盘源码采集期不变、前后相机与灯光元数据相等的检查。近景为水体诊断角度，whole与reverse沿用BASE_A/D。项目入口为scenes/terrain_editor.tscn，Forward+、4×MSAA、生产F11净屏。

Godot图形采集无着色器错误。场景回归7/7通过，包含F11、人物缺席、日夜水面高光。对照页本地图片链接已检查，浏览器渲染未实测。
